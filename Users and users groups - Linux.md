# Users
**Пользователь** - объект в Linux, который может взаимодействовать с системой.  
Он устроен следующим образом:

1. **UID** - главный идентификатор пользователя. Это числовой уникальный и не повторимый идентификатор. UID - это идентификатор для системы, чтобы система могла взаимодействовать с пользователем и пользователь мог взаимодействовать с системой.
2. **Username** - это удобно читаемое для человека имя пользователя, чтобы можно было входить в пользователя, быстро находить его и взаимодействовать с ним (например добавлять, смотреть группы). Username != UID.
3. **GID** - Primary GID для пользователя. Идентификатор группы пользователя. Этот идентификатор используется для определения принадлежности пользователей к конкретным группам, в случае с Primary GID один пользователь может иметь только один Primary GID. О видах GID я расскажу более детально чуть позже.
4. **home** - путь до домашней папки пользователя. Например `/home/admin`.
5. **shell** - путь до интерактивной оболочки. Интерактивная оболочка, грубо говоря - это штука, которая позволяет человеку удобно взаимодействовать с системой через терминал.
6. **GEOS** - это прочая информация о пользователе. Номер телефона, адрес и т.д.
# User types
|Диапазон UID|Тип пользователей|Описание|
|-|-|-|
|0|root - суперпользователь|полный контроль над системой. Ядро не проверяет права доступа|
|1-999|Системные пользователи. Без интерактивного входа|учетные записи без интерактивного входа, которые создаются для работы служб|
|1000+|Обычные пользователи|
|65534|nobody - минимально доверенные пользователи. (число 65534 взято для примера, на практике может быть другое число)|

Каждый объект в Linux имеет владельца (owner) и группу (group). Когда объект создается каким-либо пользователем, например `user1` с `UID = 1010`  и `GID = 1010`, объект получает владельца 1010 и группу 1010. 
Когда  `user2` с `UID = 1020`  и `GID = 1020` попытается как-то взаимодействовать с файлом, он получит ошибку `permission denied`, потому что он не прошел проверку прав доступа.

# Groups
Группа - это механизм коллективного доступа. Вместо того, чтобы выдавать каждому пользователю какой-то конкретные права, достаточно необходимые права выдать на группу, а самого пользователя включить в эту группу.
В Linux существует два вида GID:
1. Primary GID - уникальный идентификатор пользователя/пользователей. Нужен, чтобы при создании файлов файл получал записи о владельце и Primary GID владельца. Запись о Primary GID хранится в файле `/etc/passwd`
2. Supplementary GID - дополнительные группы для пользователя. Один пользователь может иметь множество дополнительных групп (до десятков тысяч), так же как группа может иметь множество пользователей. Запись о Supplementary GID хранится в файле `/etc/group`

|Тип пользователя|Тип группы|Отношение|
|-|-|-|
|default users|Primary GID|1:1 (во многих дистрибутивах)|
|other users|Primary GID|N:1|
|all users|Supplementary GID|M:N|
