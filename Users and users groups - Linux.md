# Users
**Пользователь** - объект в Linux, который может взаимодействовать с системой.  
Он устроен следующим образом:

</div>  

1. **UID** - главный идентификатор пользователя. Это числовой уникальный и не повторимый идентификатор. UID - это идентификатор для системы, чтобы система могла взаимодействовать с пользователем и пользователь мог взаимодействовать с системой.
2. **Username** - это удобно читаемое для человека имя пользователя, чтобы можно было входить в пользователя, быстро находить его и взаимодействовать с ним (например добавлять, смотреть группы)
3. **GID** - Primary GID для пользователя. Идентификатор группы пользователя. Этот идентификатор используется для определения принадлежности пользователей к конкретным группам, в случае с Primary GID один пользователь может иметь только один Primary GID. О видах GID я расскажу более детально чуть позже.
4. **home** - путь до домашней папки пользователя. Например `/home/admin`.
5. **shell** - путь до интерактивной оболочки. Интерактивная оболочка, грубо говоря - это штука, которая позволяет человеку удобно взаимодействовать с системой через терминал.
6. **GEOS** - это прочая информация о пользователе. Номер телефона, адрес и т.д.
# User types
|Диапазон UID|Тип пользователей|Описание|
|-|-|-|
|0|root - суперпользователь|полный контроль над системой. Ядро не проверяет права доступа|
|1-999|Системные пользователи. Без интерактивного входа|учетные записи без интерактивного входа, которые создаются для работы служб|
|1000+|Обычные пользователи|
|65534|nobody - минимально доверенные пользователи. (число 65534 взято для примера, на практике может быть другое число)|
