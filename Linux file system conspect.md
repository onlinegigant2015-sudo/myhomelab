# Структура файловой системы Linux
---
## Корень, корневой каталог (/)
Корневой каталог является верхушкой иерархии файловой системы Linux.
Он содержит в себе все каталоги системы. Доступ к изменению данных системных каталогов имеет только супер пользователь с root правами (super user). Обычный пользователь может менять файлы из своей домашней папки и /tmp.
### /bin, /sbin (binaries - исполняемые файлы, system binaries - системные исполняемые файлы) 
В этих каталогах содержатся исполняемые файлы консольных утилит
- /bin содержит в себе исполняемые файлы базовых команд, доступных любому пользователю.
- /sbin содержит в себе исполняемые файлы системных утилит, доступ к большинству утилит могут иметь только супер пользователи.
В современных дистрибутивах Linux каталоги /bin и /sbin - это лишь ссылки на каталоги /usr/bin, /usr/sbin - это сделали из-за стандарта usr merge, который был создан для упрощения иерархии файловой системы.
### /boot (загрузка)
Этот каталог содержит файлы, для загрузки системы. Здесь хранятся файлы ядра. В системах с UEFI часть настроек может храниться в /boot/efi
### /dev (devices - девайсы)
В этом каталоге хранятся файлы девайсов (устройств). Это файлы, которые являются "интерфейсами" между аппаратными девайсами и реализацией работы этих аппаратных девайсов в ОС.
Файлы устройств бывают двух видов:
- Блочные устройства (есть буферизация)
  - Жесткие диски
  - SSD
  - Флешки
- Символьные устройства (без буферизации)
  - Клавиатура
  - Мышь
  - Динамики
  - Терминалы (обычные терминалы через которые мы пишем команды)
### /etc (прочие файлы, от латинского et cetera)
Тут хранятся системные конфигурационные файлы. Настройка сети, пользователей, служб и загрузки. В этом каталоге содержатся сценарии запуска и завершения работы для старта и остановки различных программ.
### /home (домашний каталог пользователя)
Домашняя папка для обычных пользователей. Обычный пользователь может изменять, создавать, удалять файлы только в своем домашнем каталоге. К другим каталогам пользователь доступ на изменение не имеет.
### /lib (libraries - библиотеки)
Здесь хранятся файлы библиотек, необходимые для работы системы. Библиотеки для сторонних приложения, как правило, хранятся в каталоге /usr/lib
### /media (носители)
Этот каталог используется для автоматического монтирования съемных устройств (флешки, sd карты, внешние жесткие диски и так далее). Современные дистрибутивы монтируют устройства в подкаталоги /media/`<user name>`/`<device name>`
### /mnt (mount - монтированные)
Данный каталог предназначен для ручного монтирования файловых систем администраторами. В бизнесе его используют, чтобы подключиться к ftp-серверу (в моей конторе)
### /opt (optional - опциональное ПО)
Здесь хранятся файлы сторонних приложений.
### /srv (service - сервисы, службы)
Тут содержаться данные, для работы каких либо сервисов на данном сервере.
### /tmp
Каталог для хранения временных файлов. Данные удаляются при перезапуске системы.
### /proc
Виртуальная файловая система, которая дает интерфейс к внутренним структурам ядра Linux. Тут хранятся информация о процессах, данные о памяти, процессоре, загрузке, параметрах ядра и т.д.
Данные транслируются, а не хранятся на диске
### /run
Каталог временных PID-файлов, сокетов, lock-файлов.
### /var (variable - изменчивые данные)
Тут хранятся данные, которые постоянно накапливаются.
#### /var/log 
Логи системы и приложений.
#### /var/spool
Очереди для разных служб.
#### /var/lib
Внутренние данные служб
#####/var/lib/dpkg
База данных установленных пакетов
### /sys (system - файлы системы)
Это виртуальная файловая система которая дает интерфейс к файлам устройств, драйверов, подсистем ядра. Отличие от /proc. /proc — про процессы и параметры ядра, а /sys — про устройства и драйверы.
Данные транслируются, а не хранятся на диске

---
### /usr
Вторичная иерархия после каталога `/`. Тут хранятся пользовательские утилиты и приложения.
Содержит файлы для программ второго уровня (вторичная иерархия). Когда-то давно сначала запускалась основная система (до /usr), потом уже подключался этот каталог.
### Каталоги второго уровня иерархии
#### /usr/bin
Тут содержаться основные пользовательские команды.
#### /usr/sbin
Содержаться исполнительные файлы для сис. админов.
#### /usr/lib
Содержаться библиотеки, используемые каталогами `/usr/bin` и `/usr/sbin`.
#### /usr/local
Каталог для пользовательских программ которые были установлены через компиляцию исходного кода.
#### /usr/src
Содержаться исходные тексты ядра Linux (если установлены), заголовочные файлы (linux-headers-*)
# Утилиты для работы с дисками и файловыми системами
---
## `df -h` - disk free
Служит для диагностики свободного места на диске
Может использовать следующие параметры:
```bash
-h - human-readable: удобный формат для чтения человеком. Разрядность на G,M,K.
-T - показать тип файловой системы.
-i - показать inode (метаданные о файле. Права, владелец, размер и т.д.), а не байты.
-a - включить все файловые системы.
```
## `du -sh` - disk usage
Служит для диагностики, сколько места использует какой-либо каталог.
```bash
-s - summary: сумма без детализации
-h - human-readable: тоже самое, что выше.
-a - показать файлы и каталоги.
--max-depth - как глубоко будет анализировать.
```
## `lsblk` - list block devices
Показывает дерево блочных устройств и куда они смонтированы
```bash
-f --fs - file system: показывает файловую систему, UUID, точку монтирования.
-o --output=список: выбрать конкретные колонки.
-p --paths: полные пути к устройствам.
-l --list: режим отображения списка.
-a --all: показать все устройства, включая пустые.
-d --nodeps: только диски, без разделов.
-n --noheadings: без заголовков.
```
## `sudo fdisk -l` - list partition tables
Показывает таблицу разделов каждого диска.
```bash
-l - list: показать разделы и выйти.
-u - units: единицы измерения
```

# Монтирование носителей в файловую систему
В файле /etc/fstab записаны настройки монтирования носителей в систему.
- Команда `mount` служит для вывода списка смонтированных устройств в файловую систему
- Команда `mount <device> <mount path>` служит для ручного монтирования устройств в файловую систему
- Команда `mount -a` служит для монтирования устройств, которые еще не смонтировались из /etc/fstab. 
- Команда `umount` служит для размонтирования устройств из файловой системы.

# LVM - logical volume management
LVM (logical volume management) - это управление логическими пространствами, томами.
<img width="735" height="609" alt="image" src="https://github.com/user-attachments/assets/ad9c7a80-b27e-4b1b-a400-23d7045b2c50" />
Эта штука позволяет объединить несколько независимых устройств хранения (или разделов) в один логический диск, либо же в несколько логических дисков с произвольным размером.
LVM состоит из нескольких слоев:
- 0 слой (черный) - физические хранилища, разделы. Это устройства физические/логические устройства, которые друг от друга не зависят и не знают друг друга.
- 1 слой (голубой) - physical volumes (физические тома, пространства) - оболочки поверх 0 слоя. Которые позволяют быть интерактивными для LVM.
- 2 слой (оранжевый) - volume group (группы томов) - объединение нескольких независимых томов в один большой том. Свободное пространство суммируется.
- 3 слой (зеленый) - logical volumes (логические тома) - кусочки 2 слоя с определенным размером. Они независимы друг от друга.

## Настройка lvm
1. `sudo pvcreate <path into device>` - создание 1 слоя над 0
2. `sudo vgcreate <group name> <path into pv device>` - создание группы
3. `sudo lvcreate -L <...G or ...T or ...M or ...K> -n <lv name> <group name>` - создание lv
### Дополнительно
- `sudo lvextend -L +<...G or ...T or ...M or ...K> <path into lv>` - расширение места в lv
- `sudo resize2fs <path into lv>` - расширение места в файловой системе ext4
