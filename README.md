# Лаборатория: Статическая маршрутизация Mikrotik в GNS3

## Цель
Достигнуть сетевого взаимодействия между департаментами.

## Топология
<img width="448" height="507" alt="image" src="https://github.com/user-attachments/assets/ae7a0bab-25b7-459b-bca6-d03196f2447e" />

**Устройства:**
- **[R1]** — Пограничный роутер. Внутренний IP на роутеры R2D1 10.0.0.5\30, R3D2 10.0.0.1\30
- **[R2D1]** — Роутер департамента 1. IP для взаимодействия с роутером R1 10.0.0.6\30, IP департамента 10.2.1.1/30
- **[R3D2]** — Роутер департамента 1. IP для взаимодействия с роутером R1 10.0.0.2\30 IP департамента 10.3.2.1/30

**Среда:** GNS3
**Образы:** MikroTik RouterOS 7

## ⚙️ Что настроено

### [R1]
- WAN: `eth1`, IP: 192.168.254.254
- LAN 'eth2', IP: 10.0.0.5\30
- LAN 'eth3', IP: 10.0.0.1\30

### [R2D1]
- IP: `10.0.0.6/30`

### [R3D2]
- IP: `10.0.0.2/24`

## 🔧 Основные команды

```bash
# Назначение ip адреса на интерфейс
ip address add interface=eh0 address=10.0.0.2
# Просмотр IP адресов
ip address print
# Создание маршрута
ip route add gateway=10.0.0.1 dst-address=10.0.0.4/30
# Просмотр маршрута
ip route print
```
