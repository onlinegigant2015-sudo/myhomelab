# Инструменты диагностики

## `ip a`

Этот инструмент служит для вывода ip адресов. У этой команды есть куча параметров, но для быстрой диагностики часто используется параметр `-br`. Я не буду тут расписывать какой параметр за что отвечает, это можно узнать в google, в `ip --help` или в `man ip`.  
Вывод `ip a` обычно выглядит так:

```bash
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000 link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00                                          
inet 127.0.0.1/8 scope host lo                                          
valid_lft forever preferred_lft forever                                          
inet6 /128 scope host noprefixroute                                          
valid_lft forever preferred_lft forever                                          
                                      
2: <интерфейс>: <BROADCAST, MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP group default qlen 1000 link/ether <MAC интерфейса> brd ff:ff:ff:ff:ff:ff                                          
altname enx080027232330                                          
inet <ipv4_unicast/mask> brd <ipv4_broadcast> scope global <интерфейс> valid_lft forever preferred_lft forever                                          
inet6 <ipv6_unicast/mask> scope link proto kernel_11 valid_lft forever preferred_lft forever
```

Важное в этом выводе:

- Флаги состояния (`UP`,`LOWER_UP`)
- Слово `dynamic`: если такое слово есть - адрес получен от dhcp, если нет - адрес прописан вручную.

## `ip r`

Этот инструмент выводит таблицу маршрутизации.  
При помощи ее можно провести диагностику, почему нет доступа во внешний интернет. Обычно причина кроется в непрописанном или прописанном, но криво маршруте по умолчанию.  
Вывод команды должен быть таким:

```bash
default via <IP_роутера> dev <интерфейс> proto static/dhcp   ← Маршрут в интернет (шлюз)                                            
<Адрес_сети>/<маска> dev <интерфейс> proto kernel scope link src <Твой_IP> ← Локальная сеть
```

## `sudo ss -tulpn`

Этот инструмент выводит информацию о открытых портах; о программах, которые слушают эти порты; какие процессы слушают и так далее.  
Данный инструмент служит для диагностики, если какой-то сервис "отвалился", это позволяет либо подтвердить, либо исключить проблему с портами.  
Я не буду тут расписывать какой параметр за что отвечает, это можно узнать в google, в `ss --help` или в `man ss`.  
Но важные маркеры, на которые надо обращать внимание, следующие:

- Где слушает: `0.0.0.0:80` (извне) или `127.0.0.1:80` (только локально).
- State: `LISTEN` — сервис работает и ждет подключений. Если порта нет в списке — сервис упал или не запущен.

## `tcpdump`

Инструмент, который позволяет просмотреть "подкапотное пространство" работы сети. Данные можно вывести в лог, а затем его проанализировать.

## `dig`

Инструмент, при помощи которого можно просмотреть информацию о DNS. Параметр `+trace`, позволяет просмотреть весь путь разрешения имени, начиная от корневых серверов.

## `nslookup`

Инструмент, который позволяет увидеть информацию о домене, IP, авторитативный ли ответ получен или нет.

### Авторитативный ответ

Авторитативный ответ - это ответ от авторитативного сервера, который, в свою очередь, хранит все записи в своей зоне, в том числе`A` записи разрешения имен и `aliases`.

# SSH (Secure Shell)

SSH — это протокол, который позволяет удаленно управлять компьютером с ОС Linux.

Чтобы можно было подключаться по SSH к компьютеру на Linux, необходимо установить пакет `openssh-server`. После установки появятся конфигурационные файлы по пути `/etc/ssh/`. Основной файл настройки сервера — это `sshd_config`. 

По умолчанию подключение работает по 22 порту. Если в файле `sshd_config` раскомментировать и изменить строку `Port 22` на другой номер, то при подключении на клиенте нужно будет явно указывать новый порт: `ssh -p <номер порта> login@server`.

## Настройка беспарольного подключения (по ключам)
Для безопасного подключения используется асимметричное шифрование (публичный и приватный ключ RSA). 
- Публичный ключ хранится на сервере Linux в файле `~/.ssh/authorized_keys`.
- Приватный ключ хранится локально у клиента и никогда не передается по сети.

Алгоритм настройки:
1. На клиенте генерируем пару ключей: `ssh-keygen -t rsa`.
2. При помощи `scp` копируем публичный ключ на сервер: 
   `scp <путь_к_публичному_ключу> <имя_пользователя>@<ip_сервера>:~/`
3. На сервере создаем папку и добавляем ключ в список разрешенных:
```bash
   mkdir -p ~/.ssh
   chmod 700 ~/.ssh
   cat ~/<файл_ключа>.pub >> ~/.ssh/authorized_keys
   chmod 600 ~/.ssh/authorized_keys
```
После настройки беспарольного подключения, желательно отключить аутентификацию по паролю. В `sshd_config` необходимо изменить запись с `#PasswordAuthentication yes` на `PasswordAuthentication no`.

 # Firewall
 ## UFW
 `UFW` (Uncomplicated Firewall) - это упрощенная утилита для настройки фаервола ядра Linux. Данный инструмент распространен на дистрибутивах Ubuntu. Он позволяет настраивать простые правила фильтрации трафика.

У утилиты `ufw` следующий синтаксис `sudo ufw  <опции> <действия> <параметры>`

 Для проверки работоспособности утилиты `ufw` необходимо прописать команду `sudo ufw status`. Если вывод будет `Status: inactive`, нужно включить `ufw`.  
 Для включения  `ufw` используется команда `sudo ufw enable`.

### Опции UFW
`--version` - вывод версии программы.  
`--dry-run` - тестовый запуск.
### Действия UFW
`enable` - включить `ufw` и добавить его в автозагрузку.  
`disable` - выключить `ufw` и удалить его из автозагрузки.  
`reload` - перезагрузить `ufw`.  
`default` - задать политику по умолчанию, доступно allow, deny и reject, а также три вида трафика - incoming, outgoing или routed.  
`logging` - включить журналирование или изменить уровень подробности.  
`reset` - сбросить все настройки до состояния по умолчанию.  
`status` - посмотреть состояние `ufw`.  
`show` - посмотреть один из отчётов о работе.  
`allow` - добавить разрешающее правило.  
`deny` - добавить запрещающее правило.  
`reject` - добавить отбрасывающее правило.  
`limit` - добавить лимитирующее правило.  
`delete` - удалить правило.  
`insert` - вставить правило.
