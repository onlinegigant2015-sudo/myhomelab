# Systemd
`systemd` - это служба, которая позволяет гибко настривать систему. На `systemd` держится основная работа Linux.
## Структура Systemd
`systemd` состоит из нескольких служб:
- `systemctl` - менеджер служб.
- `journald` - служба журналирования событий.
    - `journalctl` - менеджер журналирования событий.
- `udev` - менеджер устройств.
- `networkd` - служба для управления сетью.
- `logind` - служба для управления сеансами пользователей.
- `timedated` - служба для управления системным временем.

Так же у `systemd` существует несколько юнитов:
- `socket` - механизм активации сервисов (service) по требованию. Он позволяет не держать службу в памяти постоянно, а запускаться при поступления к нему запроса.
- `service` - описывает процесс (демон) и команды для управления им.
- `timer` - альтернатива `cron`, позволяет планировать задачи на основе календарных выражений. Полная интеграция с зависимостями и журналированием.
- `target` - описывает, какие юниты нужно запустить.
- `path` - "датчик" событий, которые можно указать в файле конфигурации `.path`. Логика такая: если произошло какое-то событие, нужно запустить такой-то сервис.
- `mount`, `automount` - точки монтирования. `automount` обеспечивает отложенное монтирование в момент первого обращения к каталогу.
