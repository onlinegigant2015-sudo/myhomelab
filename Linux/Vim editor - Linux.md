# Режим редактирования

Для редактирования текста необходимо перейти в режим вставки (INSERT), для этого нужно нажать на клавишу `i`.
После редактирования текста необходимо выйти из режима вставки. Нужно нажать на клавишу `esc`.  

# Сохранение и выход

Чтобы сохранить данные, необхомо прописать `:w` (сокращение от write).  
Чтобы выйти, необхомо прописать `:q` (сокращение от quite).
Чтобы выйти без сохранения, нужно прописать `:q!`.  
Данные команды можно комбинировать `:wq`

# Навигация

Для навигации по тексту по символам используются стрелки и кнопки `k` - для перемещения курсора вверх, `j` - для перемещения курсора вниз, `h` - для перемещния курсора влево, `l` - для перемещения курсора вправо.  
Так же можно перемещаться по словам. Кнопка `w` - для перемещние вправо на одно слово, кнопка `b` - для перемещения влево на одно слово.

К всем командам по перемещению можно дописывать число, на которое нужно переместить курсор по символам или словам.

Чтобы перейти в начало, нужно 2 раза нажать на `g`, чтобы перейти в конец, нужно 1 раз нажать на `G`.

# Удаление символов и строк

Для удаления символом используется клавиша `d` и направление, по которому будет происходить удаление (см. раздел Навигация).  
Для удаления всей строки используется двойное нажатие на клавишу `d`.   
Для удаления символов начиная от курсора до конца строки используется клавиша `D`.

# Выеделение, копирование, вставка

Для выеделения фрагмента, необходимо перейти в режим выделения - нажать на клавишу `v`.  
Для копирования выделенного участка в буфер обмена, необхомо нажать на кнопку `y`.  
После копирования нужно выйти из режима выделения - кнопка `esc`.  
Для вставки копированного фрагмента, необходимо нажать на `p`.  

# Замена символов

Для замены одного символа нужно нажать на `r` и ввести нужный символ.  
Для замены нескольких символов, необходимо перейти в режим замены, клавиша `R`.  
После завершения замены, необходимо выйти из режима замены, клавиша `esc`

# Отмена последнего изменения, отмена отмены

Для отмены последнего изменения, необходимо нажать на `u`. 

Важное уточнение. Переключение на нужный режим и редактирование в этом режиме = 1 действие. X переключение = x действий, все что содержится внутри редактирования, не учитывается.

Для отмены отмены используется комбинация клавиш `ctrl + r`.
